# سامانه یکپارچه مدیریت HSE معدن (نسخه ۱.۰.۰)

نرم‌افزار دسکتاپ کاملاً آفلاین برای مدیریت HSE معادن، نوشته‌شده با **Python + PySide6**
و پایگاه داده لوکال **SQLite**. تمام تاریخ‌ها شمسی (جلالی) هستند و فیلدهای
`created_at` / `updated_at` به‌صورت خودکار و غیرقابل‌ویرایش توسط سیستم ثبت می‌شوند.

## چرا Python + PySide6؟
- **PySide6 (Qt6)** پایدارترین و حرفه‌ای‌ترین گزینه برای ساخت رابط کاربری دسکتاپ
  زیبا با پشتیبانی کامل از راست‌به‌چپ (RTL) فارسی و فونت سفارشی است.
- **jdatetime** تبدیل و محاسبات تقویم جلالی را به‌صورت دقیق و استاندارد انجام می‌دهد.
- **PyInstaller** امکان بسته‌بندی کل پروژه (کد + وابستگی‌ها + Python Runtime) را در
  یک فایل `.exe` مستقل و بدون نیاز به نصب Python روی سیستم کاربر نهایی فراهم می‌کند.
- حجم نهایی و سرعت اجرا برای این نوع نرم‌افزار (فرم‌محور، نه بازی/گرافیک سنگین)
  در سطح قابل قبول و مشابه راهکارهای WPF است، با سرعت توسعه بسیار بالاتر.

hse_mine_app/

├── ui/

│   ├── setup_wizard.py           # ویزارد راه‌اندازی اولیه فضای کاری
│   ├── dashboard.py               # داشبورد و KPIها
│   ├── personnel.py               # مدیریت پرسنل
│   ├── incidents.py               # مدیریت حوادث و شبه‌حوادث
│   ├── ppe.py                     # انبار PPE + تحویل PPE
│   ├── training.py                # دوره‌های آموزشی
│   ├── medical.py                 # طب کار
│   ├── disciplinary.py            # تشویق و تنبیه
│   ├── reports.py                 # خروجی Excel/CSV
│   ├── backup.py                  # پشتیبان‌گیری/بازیابی
│   └── widgets/
│       ├── sidebar.py             # منوی کناری
│       ├── crud_page.py           # کامپوننت عمومی لیست+فرم (پایه اکثر ماژول‌ها)
│       └── shamsi_date_picker.py  # Date Picker گرافیکی شمسی

هنگام اجرا به‌صورت EXE، پوشه‌های `data` / `backups` / `exports` / `assets`
**کنار فایل exe** ساخته می‌شوند (نه در پوشه موقت)، تا با هر بار اجرا داده‌ها حفظ شوند.

## اجرای پروژه در محیط توسعه

```bash
python -m venv venv
# ویندوز:
venv\Scripts\activate
# لینوکس/مک:
source venv/bin/activate

pip install -r requirements.txt
python main.py
```

> نکته فونت: برای بهترین کیفیت نمایش فارسی، فونت رایگان **Vazirmatn** را نصب کنید
> (وب‌سایت رسمی: rastikerdar/vazirmatn روی گیت‌هاب). در صورت نبود فونت، برنامه
> به‌صورت خودکار به فونت پیش‌فرض سیستم سوییچ می‌کند و مشکلی در اجرا ایجاد نمی‌شود.

## بسته‌بندی نهایی به یک فایل EXE مستقل (Windows)

از داخل محیط مجازی (venv) که در بالا ساختید، در ویندوز دستور زیر را اجرا کنید:

```bash
pyinstaller --noconfirm --onefile --windowed ^
  --name "HSE_Mine_Manager" ^
  --icon "assets\app_icon.ico" ^
  --add-data "assets;assets" ^
  main.py
```

توضیح پارامترها:
- `--onefile` : همه‌چیز در یک فایل exe واحد بسته‌بندی می‌شود.
- `--windowed` : از باز شدن پنجره کنسول سیاه جلوگیری می‌کند (اپ کاملاً گرافیکی است).
- `--icon` : آیکون اختصاصی exe (اختیاری؛ فایل `.ico` بسازید یا حذف کنید).
- `--add-data "assets;assets"` : پوشه assets (شامل لوگوی پیش‌فرض در صورت وجود) را
  داخل بسته کپی می‌کند. در لینوکس/مک به‌جای `;` از `:` استفاده کنید.

فایل نهایی در مسیر `dist/HSE_Mine_Manager.exe` ساخته می‌شود. همین یک فایل را
می‌توانید روی هر سیستم ویندوزی (بدون نیاز به نصب Python) اجرا کنید؛ با اولین اجرا
پوشه‌های `data`, `backups`, `exports`, `assets` به‌صورت خودکار کنار exe ساخته می‌شوند.

> جایگزین `--onefile`: اگر ترجیح می‌دهید زمان راه‌اندازی برنامه سریع‌تر باشد (به قیمت
> چند فایل به‌جای یک فایل)، از `--onedir` (پیش‌فرض PyInstaller بدون `--onefile`)
> استفاده کنید.

## ماژول‌های پیاده‌سازی‌شده در این نسخه
1. ویزارد راه‌اندازی اولیه فضای کاری (نام شرکت/معدن، لوگو)
2. مدیریت پرسنل
3. مدیریت حوادث و شبه‌حوادث (با پیوست فایل)
4. انبار PPE + ثبت تحویل به پرسنل
5. دوره‌های آموزشی + ثبت شرکت پرسنل
6. طب کار (ادیومتری/اسپیرومتری/عمومی) با هشدار سررسید در داشبورد
7. تشویق و تنبیه
8. داشبورد KPI با نمودار میله‌ای حوادث ۶ ماه اخیر (QtCharts)
9. خروجی Excel/CSV از تمام جداول
10. پشتیبان‌گیری/بازیابی دیتابیس

## نکات فنی مهم
- **فیلدهای Audit**: `created_at` و `updated_at` هرگز در فرم‌ها نمایش داده نمی‌شوند؛
  فقط توابع `insert_row` / `update_row` در `core/database.py` آن‌ها را با
  `now_shamsi_datetime_str()` پر می‌کنند، بنابراین کاربر امکان دستکاری آن‌ها را ندارد.
- **فرمت ذخیره تاریخ**: رشته‌ی `YYYY/MM/DD` (و برای Audit: `YYYY/MM/DD HH:MM:SS`)
  که چون طول ثابت و صفر-پرشده دارد، مرتب‌سازی متنی آن هم صحیح است.
- **کامپوننت CRUD عمومی** (`ui/widgets/crud_page.py`): اکثر ماژول‌ها (پرسنل، PPE،
  آموزش، طب کار، تشویق/تنبیه) بر پایه این کامپوننت ساخته شده‌اند تا کد تکراری کم شود
  و افزودن فیلد/ماژول جدید در آینده بسیار سریع باشد — کافی است لیست `FIELDS` را
  در فایل ماژول موردنظر ویرایش کنید.

## پیشنهاد گام‌های بعدی (خارج از محدوده نسخه فعلی)
- تبدیل فیلد «شناسه کالا» در تحویل PPE و «شناسه دوره» در ثبت آموزش، به Combo Box
  اختصاصی (در حال حاضر عدد ساده است تا کاربر شناسه را از لیست مربوطه وارد کند).
- افزودن سیستم کاربران/نقش (مدیر HSE، سرپرست، بازرس) با رمز عبور محلی، در صورت نیاز.
- افزودن فرم چاپ رسمی گزارش حادثه (PDF) با سربرگ و لوگوی شرکت.
- Cascade کردن کسر خودکار موجودی انبار PPE هنگام ثبت هر تحویل.
